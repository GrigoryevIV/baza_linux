Инструкция по запуску
Чтобы открыть сайт локально, выполните следующие действия:

Запустите локальный сервер (если он еще не запущен):

cd /home/user/MyProject/Basis_linux
python3 -m http.server 8080
Откройте сайт в браузере: Перейдите по ссылке: http://localhost:8080/basis.html

Редактирование
Файлы сайта находятся в папке /home/user/MyProject/Basis_linux. Вы можете редактировать HTML файлы в любом текстовом редакторе.

Главная страница курса: basis.html
Уроки: находятся в подпапках basis/
