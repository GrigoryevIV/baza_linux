Справочник команд Linux

05. Текстовый интерфейс пользователя

  • ls - вывести список файлов и директорий
  • ls -i - показать номера inode
  • ls --help - справка по команде ls
  • man - открыть руководство по команде
  • man -k - поиск команд по ключевому слову
  • info - альтернативная система документации
  • history - история выполненных команд
  • !! - повторить последнюю команду

06. Пути и директории

  • pwd - показать текущую директорию
  • cd - сменить директорию
  • mkdir - создать директорию
  • mkdir -p - создать вложенные директории
  • rmdir - удалить пустую директорию
  • rm -r - удалить директорию рекурсивно
  • ls -R - рекурсивный вывод содержимого

07. Создание и копирование файлов

  • touch - создать пустой файл или обновить время
  • ls -a - показать скрытые файлы
  • cp - копировать файлы
  • cp -v - копировать с выводом процесса
  • cp -i - запрашивать подтверждение при перезаписи
  • cp -n - не перезаписывать существующие файлы
  • cp -u - копировать только новые файлы
  • cp -l - создать жесткие ссылки вместо копирования
  • cp -r - копировать директории рекурсивно
  • cp -a - архивное копирование (сохранить атрибуты)

08. Перемещение, переименование, удаление. Ссылки

  • mv - переместить или переименовать файл
  • mv -v - переместить с выводом процесса
  • rm - удалить файл
  • rm -v - удалить с выводом процесса
  • rm -r - удалить директорию рекурсивно
  • rm -f - принудительное удаление без подтверждения
  • ln - создать жесткую ссылку
  • ln -s - создать символическую ссылку
  • ln -v - создать ссылку с выводом процесса
  • ls -l - подробный вывод списка файлов

09. Чтение текстовых файлов

  • cat - вывести содержимое файла
  • cat -n - вывести с нумерацией строк
  • tac - вывести файл в обратном порядке
  • less - постраничный просмотр файла
  • head - показать начало файла
  • head - - показать N первых строк
  • tail - показать конец файла
  • tail - - показать N последних строк
  • tail -n - указать количество строк
  • tail -f - следить за изменениями файла
  • grep - поиск текста в файлах
  • grep -n - показать номера строк
  • grep -r - рекурсивный поиск
  • grep -l - показать только имена файлов
  • grep -v - инвертировать поиск (не содержит)
  • grep -i - игнорировать регистр букв при поиске
  • grep -c - подсчитать количество вхождений
  • grep -o - показать только совпадающие части

10. Текстовые редакторы

  • nano - простой текстовый редактор
  • vi - классический редактор Vi
  • vim - улучшенная версия Vi

11. Стандартные потоки

  • > - перенаправить вывод в файл (перезапись)
  • >> - добавить вывод в конец файла
  • 2> - перенаправить ошибки
  • &> - перенаправить вывод и ошибки
  • | - передать вывод команды на вход другой
  • tee - вывести на экран и записать в файл

12. bash №1: bash-completion, alias, type

  • alias - создать псевдоним команды
  • ls -d - показать только директории
  • type - показать тип команды
  • type -a - показать все варианты команды

13. bash №2: переменные

  • echo - вывести текст или значение переменной
  • env - показать переменные окружения
  • export - экспортировать переменную
  • $() - подстановка команды

14. Процессы №1: Информация о процессах

  • ps - показать процессы
  • ps -e - показать все процессы
  • ps -f - полный формат вывода
  • less -S - отключить перенос строк
  • watch - периодически выполнять команду

15. Процессы №2: Мониторинг

  • top - интерактивный монитор процессов
  • w - показать залогиненных пользователей
  • ulimit - показать лимиты ресурсов
  • ulimit -u - лимит процессов пользователя
  • ulimit -v - лимит виртуальной памяти
  • nice - запустить с приоритетом
  • nice -n - указать уровень приоритета
  • renice - изменить приоритет процесса
  • renice -n - указать новый приоритет
  • htop - улучшенный монитор процессов

16. Процессы №3: Управление процессами

  • kill - отправить сигнал процессу
  • kill -l - список доступных сигналов
  • kill -9 - принудительно завершить процесс
  • kill -SIGKILL - то же что kill -9
  • pkill - завершить процессы по имени
  • pkill -19 - приостановить процессы
  • pkill -18 - возобновить процессы

17. su

  • wc -l - подсчитать количество строк
  • exit - выйти из сеанса
  • su - переключиться на другого пользователя
  • su - - войти с окружением пользователя
  • su -c - выполнить команду от имени пользователя

18. sudo

  • sudo - выполнить команду от имени root
  • sudo -s - запустить shell от имени root
  • sudoedit - редактировать файл через sudo
  • visudo - редактировать файл sudoers
  • visudo -f - редактировать указанный файл
  • hostname - показать имя хоста
  • groups - показать группы пользователя
  • which - найти путь к исполняемому файлу

19. Пользователи

  • id - показать UID и GID пользователя
  • newgrp - сменить текущую группу
  • chage - управление сроком действия пароля
  • chage -l - показать информацию о пароле
  • useradd - создать пользователя
  • useradd -D - показать настройки по умолчанию
  • useradd -b - указать базовую директорию
  • useradd -d - указать домашнюю директорию
  • useradd -c - добавить комментарий
  • useradd -g - указать основную группу
  • useradd -G - добавить в дополнительные группы
  • useradd -u - указать UID
  • passwd - изменить пароль
  • usermod - изменить параметры пользователя
  • usermod -m - переместить домашнюю директорию
  • usermod -aG - добавить в группы
  • userdel - удалить пользователя
  • userdel -r - удалить с домашней директорией
  • groupadd - создать группу
  • groupmod - изменить группу
  • groupdel - удалить группу
  • gpasswd - управление группой
  • gpasswd -A - назначить администратора группы
  • gpasswd -M - установить список членов группы
  • gpasswd -a - добавить пользователя в группу
  • gpasswd -d - удалить пользователя из группы
  • lid - показать группы пользователя
  • lid -g - показать членов группы

20. Права на файлы

  • ls -l - показать права доступа
  • chown - изменить владельца файла
  • chown -R - рекурсивно изменить владельца
  • chown -v - изменить с выводом процесса
  • chgrp - изменить группу файла
  • chmod - изменить права доступа
  • chmod -v - изменить с выводом процесса
  • chmod -R - рекурсивно изменить права
  • chmod [+-=][rwxts] - символьный режим chmod
  • umask - установить маску создания файлов
  • umask -S - показать маску символьно
  • getfacl - показать ACL файла
  • setfacl - установить ACL
  • setfacl -m - изменить ACL
  • setfacl -b - удалить все ACL
